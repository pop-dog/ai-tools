# README quality guidelines are baked into the skill, not fetched at runtime

The generate-readme skill embeds its README quality guidelines directly in SKILL.md rather than fetching the awesome-readme list at runtime. We derived the guideline set by sampling six well-regarded READMEs from the awesome-readme list and fixed the result in the skill's Checklist. The alternative — fetching and re-deriving guidelines on each invocation — would make the skill slower, fragile against network failures or upstream changes, and non-deterministic across runs. The trade-off is that guidelines go stale without a deliberate skill update, but that is preferable to a skill that fails or drifts silently at runtime.

The six samples were httpie/httpie, ai/size-limit, alichtman/shallow-backup, sindresorhus/awesome, nlohmann/json, and othneildrew/Best-README-Template. They converge on a consistent shape: an above-the-fold hook (logo or banner, a one-sentence tagline, a badge row), an overview that frames *why* the project matters rather than only listing features, concrete usage shown as code, and depth-seeking content linked out rather than dumped inline. Specific evidence shaped individual Checklist rules: httpie satisfies "installation" purely with a link, so the Checklist accepts a link in place of inline steps; nlohmann/json keeps short illustrative snippets in the README but links its full API reference out, which is the model for the "full API reference" disqualifying trigger; shallow-backup, httpie, and size-limit all lead with an animated GIF or screenshot, so a visual demo is recommended for any tool with visible output; Best-README-Template and the longer samples use a (often collapsible) table of contents, recommended past roughly six sections.

The sampling validated the existing four-bucket taxonomy — Required, Recommended, Disqualifying, Style — rather than replacing it, so we kept the buckets and refined their contents against the evidence above. This ADR supersedes the original version, which recorded the bake-in-versus-fetch decision but did not name the examples or what each demonstrated, leaving the guidelines unjustified.
